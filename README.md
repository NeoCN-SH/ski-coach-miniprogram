# 雪遇教练 · 微信小程序框架

面向双板滑雪爱好者与教练的信息撮合平台 MVP。项目使用微信小程序原生 JavaScript、WXML、WXSS 编写，无第三方依赖。

## 已包含

- 首页：品牌入口、热门雪区、精选教练
- 找教练：关键词、城市、课程阶段、可预约状态筛选
- 教练详情：资质、评分、擅长课程、介绍、档期与参考价格
- 收藏：本地持久化收藏
- 我的：体验登录、预约/咨询入口、教练入驻入口
- 组件化教练卡片及本地模拟数据

## 运行

1. 打开微信开发者工具。
2. 选择“导入项目”，目录指向本文件夹。
3. 使用测试号，或将 `project.config.json` 中的 `appid` 替换为真实小程序 AppID。
4. 点击编译即可预览。

## 项目结构

```text
├─ components/coach-card/   教练卡片组件
├─ data/coaches.js          本地模拟数据
├─ pages/
│  ├─ home/                 首页
│  ├─ coaches/              教练搜索与筛选
│  ├─ coach-detail/         教练详情
│  ├─ favorites/            收藏
│  └─ profile/              个人中心
├─ app.js / app.json        全局逻辑与路由
└─ project.config.json      开发者工具配置
```

## 接入真实业务的建议顺序

1. 登录与用户体系：微信登录凭证换取平台 token。
2. 教练审核：实名、证书、雪场及服务项目后台审核。
3. API 层：将 `data/coaches.js` 替换成统一的 `services/` 请求模块。
4. 预约闭环：课程 SKU、档期锁定、订单、支付、退款。
5. 内容治理：评价审核、举报、隐私与平台服务协议。

> 当前版本为前端框架和交互原型，预约、咨询、支付及认证入口均为演示状态。
